Tumor branching model: simulation and analysis

Code tour: how the simulation works and what the analyses do

The program does two things: it uses one single-cell rule to simulate tumors stochastically (simulation.py), and it uses the same rule to derive theory that checks and interprets the simulation results (analysis.py). The other files only repeat runs, save data and draw figures.

Code architecture

  • One cell-level rule drives both the simulation and the theory, so the theory is an independent check on the code.

Model and code: one cell, one generation

Single-cell rule: discrete-time stochastic branching process

Concept

Each cell independently leaves 0, 2 or 3 daughters per generation, with probabilities set only by (d, q, k) ⇒ a discrete-time stochastic branching process; the offspring distribution is fully described by f(z) (mutation is ignored here).

d: probability of dying in a generation (leaves 0 daughters)
q: probability that a surviving cell makes 3 daughters (otherwise 2)
k: extra kill probability from therapy (sensitive 0.90, resistant 0.04)

Key math

P(0) = d, P(2) = (1−d)(1−q), P(3) = (1−d)q
P(n) = probability that one cell leaves n daughters after one generation (death = 0); a cell never leaves exactly 1
f(z) = d + (1−d)[(1−q)z2 + qz3]
probability generating function: the coefficient of zj = probability of leaving j daughters
m = f′(1) = (1−d)(1−k)(2+q)
mean offspring; E[Nt] = N0 mt
s = f(s)
fixed point s: probability that one cell's lineage eventually dies out; iterating s ← f(s) from s = 0 converges to the smallest root. If m > 1 then s < 1; if m ≤ 1 then s = 1.

Key points

  • I store the tumor as genotype → count, not as individual cells.
  • Two binomial draws per genotype are exactly equivalent to flipping a coin for every cell — just faster.
  • Therapy acts on natural survivors, so total death is 1 − (1−d)(1−k).
  • Mutations happen in daughters after division; their effect starts next generation.

Key points

  • A genotype is a 22-bit integer; mutation is a bitwise OR.
  • Mutation only relabels cells — the total count is conserved.

Main result: therapy, nadir, relapse

Key points

  • The winners after therapy are resistant genotypes that also carry an oncogene.
  • Same outcome in every trial, different genotypes each time — convergent phenotype, divergent genotype.
  • Passengers hitchhike along with whichever resistant clone happens to win.

Assignment scenario: one-hit vs two-hit

Key points

  • With one hit, TSG loss spreads within a few generations; with two hits it barely appears in eighteen.
  • A tumor suppressor is recessive at the cell level: one working allele is enough, so the first hit is silent and gets no selective advantage — it only drifts. The advantage appears only after the second allele of the same gene is lost, roughly μ squared per cell unless the first-hit clone happens to expand first. That waiting time delays two-hit loss: 0.07 percent of cells by generation 18, versus 27.9 percent when one hit is enough.

  • Higher death rate means more turnover: more divisions to reach the same size, so more mutations.

From description to prediction: theory vs simulation

Goldie–Coldman cure curve

Question: how large can a tumor grow before treatment starts and still be cured completely?

In one sentence

The later therapy starts and the larger the tumor, the more likely it already hides resistant cells; if a single resistant lineage survives, the tumor grows back. So the chance of cure drops steeply with tumor size.

Core idea: cure ⇔ no resistant lineage survives therapy. So compute the expected number of resistant lineages that survive (Λ); the cure probability is the chance that there are none.

Number of lineages: what decides extinction

What decides cure is the number of resistant lineages that survive therapy, Λ, not the number of resistant cells: if one lineage survives, the tumor grows back. This follows from three model assumptions:

  1. Irreversible mutation: resistant cells never revert, so a resistant lineage stays resistant as long as it survives.
  2. Independent lineages: one lineage's survival does not affect another's, so each lineage's survival probability can be computed separately and combined.
  3. Rare, independent mutational origins: each resistant lineage comes from one independent, rare mutation, so the number of surviving lineages is Poisson distributed.

Why the theory curve is a staircase

The tumor does not grow continuously; it jumps ×1.43 per generation. For example, thresholds of 150 and 200 are both first reached in generation 2 (about 204 cells), so therapy actually starts at the same moment and the cure probability is the same; hence the staircase.

Variables in the formulas

T: generations of growth before therapy (from 100 cells to the threshold size)
i: generation in which a resistant mutation arises (i = 1, …, T; written s in the code)
Si: sensitive cells in generation i; ST: sensitive cells when therapy starts
m: mean offspring per cell without therapy
μ: probability that a daughter cell acquires the resistance mutation
f(z): offspring generating function without therapy; f(n): f applied n times in a row (a lineage after n generations)
fon: offspring generating function of resistant cells on therapy
qon: probability that one resistant lineage eventually dies out on therapy (fixed point of fon)
mS,on: mean offspring of sensitive cells on therapy (< 1, shrinking each generation)
Λpre, Λon: expected numbers of resistant lineages that arise before / during therapy and survive; Λ = Λpre + Λon
L: number of resistant lineages that actually survive (a random variable); ℓ: a possible value of L, 0, 1, 2, …

Key math

qon = fon(qon) = 0.479
probability that one resistant lineage eventually dies out on therapy
Λpre = Σs=1..T μmSs−1 · [1 − f(T−s)(qon)]
expected number of clones that arise before therapy and survive
Λon = μST · mS,on / (1−mS,on) · (1−qon)
expected number of resistant clones that arise during therapy by mutation of remaining sensitive cells and survive
With rare, approximately independent mutations, so that the Poisson approximation holds, the number of surviving resistant lineages L follows:
L ~ Poisson(Λ)
The Poisson distribution is:
P(L=ℓ) = Λ^ℓ e^−Λ / ℓ!
and cure requires:
L = 0
so:
P(cure) = P(L=0) = e^−Λ

Key points

  • The theory reuses the same offspring law as the simulation — iterate s ← f(s) from zero. I iterate rather than use a closed-form solution so the same method still works if the model later allows more than three daughters: for any offspring law, iterating from zero converges to the smallest root.

Limitations and wrap-up

Key points

  • Limitations: no space, no immune system, no quiescent cells, and the mutation rate is inflated for a short demo.
  • Bands are ten-to-ninety percent ranges across trials, not confidence intervals, and I did not pick seeds.
  • A genotype in my model is not a lineage — the same genotype can arise independently.
