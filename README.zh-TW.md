# BME 6120 — 腫瘤定量模型

[English](README.md) | **繁體中文**

這是一個治療下腫瘤的隨機、離散世代分枝模型。每個細胞不是死亡，就是分裂成兩個或三個子細胞；子細胞可能發生不可逆的突變。專案先模擬 30 個腫瘤，再用同一條單細胞規則推導、完全不擬合參數的分枝過程理論，來檢驗模擬結果。

**主要論點：治療不會製造抗藥性，而是把本來就存在的抗藥細胞篩選出來。**

所有參數都是教學假設，不是臨床估計值。

> **從這裡開始：[`presentation/tumor_branching_model.pdf`](presentation/tumor_branching_model.pdf)** 是最終報告，內容與版面和網頁 [`presentation/web/index.html`](presentation/web/index.html) 相同；網頁可離線用任何瀏覽器開啟。

## 模型

| 規則 | 數值 | 原因 |
| --- | --- | --- |
| 起點 | 100 個未突變細胞 | 數量夠小，早期抗藥突變才會稀少 |
| 基因 | 3 個 oncogene、1 個抗藥基因、2 個抑癌基因（各兩個等位基因）、14 個中性 passenger | passenger 是功能基因的中性對照 |
| 一代 | 每個細胞以機率 d 死亡，否則以機率 q 產生 3 個子細胞，其餘產生 2 個 | 同時有成長與真實滅絕機會的最簡單規則 |
| 預設值 | d = 0.30、q = 0.04 → 平均子代數 m = (1−d)(2+q) = 1.428 | 超臨界（m > 1）：腫瘤會長大，但單一家系常會滅絕 |
| Driver | 活化的 oncogene 或失活的 TSG 會降低 d、提高 q | 每一類只算一次，兩類效果相加 |
| 突變 | 每個子細胞每個未突變位元以 μ = 0.001 不可逆地翻轉 | 比真實突變率高，讓效果在約 30 代內出現 |
| 治療 | 腫瘤第一次達到 20,000 個細胞的那一代開始並持續；額外殺傷 k：敏感 0.90、抗藥 0.04 | 殺傷作用在自然存活者上：總死亡 = 1 − (1−d)(1−k) |
| 停止 | 滅絕、10⁶ 個細胞或第 75 代 | 10⁶ 是計算上限，不是承載量 |

**實作方式與原因：**
- 腫瘤是字典 `{基因型: 細胞數}`，基因型是 22 位元整數（20 個基因，加上每個 TSG 的第二等位基因位元）。同基因型的細胞命運機率相同，所以整個基因型用兩次二項抽樣更新（先抽存活者，再抽三子分裂者）。這和逐細胞擲硬幣的分布完全相同，但快很多。
- 突變是對基因型做位元 OR，只是把細胞從一格移到另一格，細胞總數守恆（有單元測試）。
- 一代內的順序：治療殺傷 → 存活與分裂 → 子細胞突變。新突變因此從下一代才生效，而且治療不會改變 μ：抗藥性只能事先隨機出現。
- 基因型不等於家系：同一個基因型可能獨立出現不只一次。

模型不包含空間結構、免疫、資源競爭與靜止細胞。

## 結果

以下數字來自預設執行（除特別註明，每組 30 次試驗）。

### 1. 治療開始時抗藥細胞早已存在（圖 01、Muller 圖）

![治療下的腫瘤](output/plots/tumor_dashboard.png)

- 每個腫瘤在第一次達到 20,000 個細胞時開始治療，落在第 14–16 代（中位數 15）。
- **30 次試驗中 30 次在治療開始時就已經有抗藥細胞**（中位數占腫瘤 1.2%）。
- 治療下敏感細胞的平均子代數是 0.143，約六代內消失；抗藥細胞仍以每代 ×1.371 成長。腫瘤縮到最小值中位數 814 個細胞後又長回來：**30 次中 30 次復發**，中位數在治療開始後 13 代（範圍 9–16）。
- Muller 圖（`output/plots/genotype_evolution/muller_top_genotypes_zh.png`）顯示誰接手：同時帶有 oncogene 的抗藥基因型。每次試驗結局相同，但每次接手的基因型不同。

**復發**的定義：負荷先降到治療開始時的負荷以下，之後再回到該負荷。觀察期內沒有復發會另外記錄，不視為治癒。

### 2. One-hit 與 two-hit 抑癌基因（圖 03）

![One-hit 與 two-hit](output/plots/one_hit_vs_two_hit.png)

不治療、觀察 18 代，三組各 30 次，只差在 TSG 規則：對照組（TSG 失活沒有優勢）、one-hit（任一等位基因即可）、two-hit（同一基因兩個等位基因都要失活）。

| 組別 | 第 18 代達到 TSG 門檻的細胞 | 第 18 代負荷中位數 |
| --- | --- | --- |
| 對照 | 0.05% | 76,446 |
| One-hit | 27.9% | 94,618 |
| Two-hit | 0.07% | 73,879 |

中位數的兩兩置換檢定：對照 vs one-hit p < 0.0001、one-hit vs two-hit p < 0.0001、對照 vs two-hit p = 0.31。

**原因：**隱性抑癌基因的第一擊沒有優勢，只能隨機漂移；要等同一基因的第二個等位基因也失活才有優勢，每個細胞的機率約為 μ²。所以 18 代內 two-hit 腫瘤和對照組分不出差別。正確的說法是「18 代內還看不出差別」，而不是「two-hit 沒有效果」。

### 3. 死亡率越高，同樣大小的腫瘤越多樣（圖 02）

![死亡率與異質性](output/plots/death_rate_heterogeneity.png)

每次試驗在第一次超過 5,000 個細胞的那一代，無放回地取樣 5,000 個細胞一次。

| 死亡率 d | 淨成長 m | 長到 5,000 細胞的代數（中位數） | Shannon 多樣性（中位數） |
| --- | --- | --- | --- |
| 0.20 | ×1.63 | 8 | 1.06 |
| 0.35 | ×1.33 | 14 | 1.80 |
| 0.45 | ×1.12 | 26.5 | 2.83 |

三組兩兩皆不同，p < 0.0001。**原因：**細胞死得越多，腫瘤要經過越多代、越多次分裂才能長到同樣大小，因此累積越多突變。只看腫瘤大小，看不出它的演化歷史。

### 4. 不擬合參數的理論預測治癒（圖 08，Goldie–Coldman）

![Goldie–Coldman 治癒曲線](output/plots/therapy_analysis/goldie_coldman.png)

在 100 到 5,000 個細胞之間的 11 種腫瘤大小開始持續治療，每種 200 次。治癒指腫瘤最終滅絕。

| 治療起點（細胞） | 模擬治癒 | 理論治癒 | 存活抗藥家系數 Λ |
| --- | --- | --- | --- |
| 100 | 99.5% | 99.1% | 0.009 |
| 300 | 60.5% | 54.6% | 0.61 |
| 500 | 40.0% | 38.8% | 0.95 |
| 1,000 | 10.0% | 11.9% | 2.1 |
| 2,000 | 0.5% | 1.1% | 4.5 |
| 5,000 | 0% | ≈ 0% | 9.5 |

**理論怎麼算：**治癒代表沒有任何一個抗藥家系撐過治療。抗藥突變從成長中的敏感族群以 Poisson 過程出現；在治療前第 i 代出現的 clone 已經成長了 T − i 代，存活機率是 1 − f^(T−i)(q_on)，其中 q_on = 0.479 是單一抗藥家系在治療下滅絕的機率。把這些加總得到 Λ，也就是預期存活的抗藥家系數，而 P(治癒) = e^(−Λ)。理論在約 **416 個細胞**（Λ = ln 2）跌破 50% 治癒，且在每種大小都和模擬吻合。

**為什麼成立：**三個假設讓家系數成為決定性的量：突變不可逆、家系獨立演化、突變起源稀少且獨立。滅絕機率是從 0 反覆代入 s ← f(s) 求得，而不是解多項式，這樣之後模型若允許超過三個子細胞，同一段程式仍然適用。

### 5. 負荷 × 抗藥比例座標下的期望流向（相圖 05）

`output/plots/phase_plots/phase_field_burden_logit_zh.png` 在（腫瘤大小，抗藥比例的 logit）的每一點畫出理論上一代後的期望變化，灰線是 30 條實際軌跡。不治療時抗藥比例幾乎不變（抗藥是中性的）。治療下 logit 每代約上升一個 10 倍（log₁₀(1.371/0.143) = 0.98），所以每條軌跡都走同樣的 C 形轉彎：負荷下降、抗藥細胞接手，接著幾乎全是抗藥細胞的腫瘤重新長大。

### 保留在輸出中的其他分析

以下沒有放進最終報告，但圖與資料都在 `output/`：

- **復發時間預測**（`therapy_analysis/relapse_time_prediction`）：只用治療開始時的基因型，讓每個抗藥基因型以自己的速度成長，30 次中有 24 次準確預測到復發世代（平均誤差 0.2 代；只用單一成長率則為 2.0 代）。
- **參數敏感度**（`therapy_analysis/parameter_sensitivity`）：單純抗藥細胞在 k_R = 0.30 停止成長，但要約 0.41 才能治癒，此時連帶 oncogene 的抗藥細胞也停止成長；μ 越高，這類細胞越可能事先存在。
- **適應性治療**（`therapy_analysis/adaptive_therapy`）：沒有競爭時，暫停治療只是讓抗藥細胞先跑（惡化時間 11 vs 13 代）。有承載量競爭（K = 30,000）時，適應性治療延後惡化（16 vs 14 代，30 組配對全部較長），用藥時間約 44%。
- **基因頻率**（`genotype_evolution/gene_mutation_frequencies_zh`）、S–R 相圖（`phase_plots/phase_portrait`）、適應度 × 抗藥比例相場，以及矩陣到流向圖（`mathematical_model/matrices_to_flow`）。

## 方法上的選擇與原因

- **報告試驗間變異，而非信賴區間。**色帶是各試驗的第 10–90 百分位。試驗越多摘要越穩定，但不會消除生物的隨機性。
- **以置換檢定比較中位數。**負荷與多樣性的分布偏斜，圖上畫的也是中位數，所以直接檢定中位數差（雙尾、20,000 次打亂，以 NumPy 實作）。
- **保留每一次試驗。**滅絕的試驗以 0 延續；超過 10⁶ 細胞上限後的值視為缺失，不用最後的值補；沒達到目標大小的試驗也留在 CSV。沒有挑選好看的 seed。
- **以固定大小的樣本比較多樣性。**在同一大小比較腫瘤需要同樣大小的樣本，否則跨過門檻較多的快速腫瘤，只因比較大就看起來不同。
- **理論作為獨立檢驗。**理論重用單細胞規則，但完全不用模擬資料。吻合代表程式與推理都對；不吻合則指向隨機性或理論忽略的基因型細節。
- **每個實驗用獨立的 seed 區段**，改動一個實驗不會影響其他實驗。

## 程式說明

- 從 `simulation.py` 開始讀：`Config` → 基因型與表型 → `growth_probabilities` → `mutate_offspring` → `simulate` → `therapy_outcome`。
- 註解與 docstring 以中文撰寫，並在旁邊附英文版本。
- `experiments.py` 只回傳一般資料，`plot_*` 模組只負責畫圖，兩邊都可以單獨重用。
- 程式以 black 排版（`pyproject.toml`）。相圖與基因型圖同時輸出英文（`_en`）與繁體中文（`_zh`）版本。
- `code/presentation_build/` 是產生 `presentation/slides/` 與 `presentation/archive/` 舊簡報與提示卡的腳本。它們依行號擷取程式並引用已刪除的功能（IL11），重新使用前需要更新。

在 Python 中呼叫模型：

```python
from simulation import Config, simulate   # 在 code/ 內執行

result = simulate(Config(suppressor_hits=1, mutation_rate=0.0005), seed=7)
print(result.history[-1]["total"])
```
